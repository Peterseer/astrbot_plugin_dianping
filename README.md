# AstrBot 大众点评餐厅推荐插件

让 AstrBot 的 LLM 根据“在哪里、想吃什么”查询大众点评，结合评分、评论量和匹配度推荐餐厅。结果会提供页面能取得的招牌/推荐菜、菜品独立标价（如有）、人均消费、地址和大众点评链接。电话默认不查询，只有用户明确索要时才按店铺查询。

## 功能

- LLM 工具 `search_dianping_restaurants`：按城市、地点和口味搜索并重排餐厅。
- LLM 工具 `get_dianping_restaurant_phone`：只在用户明确需要时查询商户公开电话。
- `/点评推荐 地点 | 想吃什么`：不依赖 LLM 自主工具选择的直接命令。
- `/点评电话 完整店名`：查询最近推荐店铺的电话；推荐结果默认不显示内部 `shop_id`。
- `/点评状态`：检查 Cookie 及电话接口参数是否已配置。
- 支持原项目的 WOFF 动态字体映射，不使用 OCR。
- 地址支持搜索页、详情页、JSON-LD、隐藏信息接口及商户相册页多级回退。
- 缓存、串行限速、访问验证检测；遇到验证时停止，不会无限重试。

## 安装和配置

插件目录应位于 AstrBot 的 `data/plugins/astrbot_plugin_dianping`。安装依赖后，在 AstrBot WebUI 的插件配置中填写：

1. `cookie`：登录大众点评网页版后，在浏览器开发者工具的 Network 面板打开一个大众点评请求，从 Request Headers 复制完整 `Cookie`。
2. `user_agent`：复制同一浏览器请求的 `User-Agent`。Cookie 与 User-Agent 应保持一致。
3. `default_city_id`：LLM 没能识别城市时使用。默认 `1` 是上海；完整城市表在 `assets/location.md`。
4. `request_interval_seconds`：建议保留 2-5 秒。大众点评风控严格，不要为了速度设得过低。
5. 可选 `uuid`、`tcv`：用于尝试电话隐藏信息接口。没有这两个值时，仍会解析详情页直接展示的电话。

`uuid` 一般对应 Cookie 中 `_hc.v` 的值；`tcv` 可从大众点评 `shopDynamic` 网页接口的查询参数取得。两者需要与当前 Cookie 会话匹配。

## 对话示例

启用插件提供的两个 LLM 工具后，可以直接问：

```text
香港西九龙站附近有什么适合两个人吃的粤菜？人均 300 港币以内。
```

```text
广州天河体育中心附近想吃潮汕牛肉火锅，推荐几家评分高的，列一下招牌菜和价格。
```

继续追问：

```text
把第二家的电话给我。
```

直接命令示例：

```text
/点评推荐 广州天河体育中心 | 潮汕牛肉火锅
/点评电话 潮牛馆（体育西店）
/点评状态
```

## 数据说明

- “菜价”只会在页面为某道菜给出独立价格时展示；`人均` 不会被当作菜价。
- 推荐菜有时只有名称而无价格，这是大众点评页面本身没有提供独立标价。
- “附近”通过大众点评的城市搜索与地点关键词实现，不等同于精确 GPS 距离排序。
- 页面字段、Cookie 和接口随时可能变化。若提示访问验证，请先在浏览器完成验证并更新 Cookie，不要让 Bot 高频重试。
- 电话属于店铺公开联系方式，但仍建议只在用户明确需要时返回。

## 测试

在插件上级目录执行：

```powershell
python -m pytest astrbot_plugin_dianping/tests -q
```

单元测试不访问大众点评网络。真实查询需要有效 Cookie，因此应在 AstrBot 中做一次低频手工验收。
